Staging (freya), embedded with no iframe. Four slots on one page share one loader. All staging tests · OTA search widget

The list only shows when Embeddable widgets → Activities list is switched on for the wandr public storefront in staging Platform.Admin.

1. Default snippet

Expect: up to 4 Ubud activities in the storefront currency (AUD), under the title and description set in Admin (none while those fields are empty). Cards link to the activity detail page on wandr-v3.freya.

2. Overrides from the page

Expect: up to 8 Sydney activities in USD, the title and description below, and a carousel with arrows in the header. Card links carry ?currency=USD.

3. Fallbacks

Expect: GBP is not sold, so prices fall back to AUD. data-limit="99" caps at 12. The empty data-title and data-description hide the heading.

4. Empty state

Expect: the agreed "no activities" message, not an error and not a blank box.
